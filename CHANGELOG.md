# WPBakery Category Image Grid - Changelog

## [1.0.0] - 2025-01-16

### Added
- Initial release of WPBakery Category Image Grid
- Single post type selection with category filtering
- Category toolbar with "All [Post Type]" option
- Responsive grid layout with 4:3 aspect ratio
- Multiple pagination types (load all, top N, lazy loading, pagination)
- Hover effects with overlay and customizable button
- Smooth animations for category changes
- Polylang multilingual compatibility
- AJAX-powered content loading
- Fully responsive design for mobile/tablet/desktop
- Vanilla JavaScript implementation (no jQuery dependency)
- WPBakery Page Builder integration
- Comprehensive documentation and quick guide

### Features
- Category-based filtering within single post type
- Dynamic toolbar with "All" + category options
- Grid columns: 2-6 configurable
- Gap size customization
- Four pagination modes
- Hover overlay with title and button
- Fade in/out animations
- Staggered item animations
- Loading states and error handling
- Accessibility support
- Polylang language filtering

### Technical
- AJAX endpoints for dynamic loading
- Data attributes for configuration
- Custom events for extensibility
- Modular JavaScript class structure
- CSS Grid layout system
- Mobile-first responsive design
- Multilingual post type and category handling
